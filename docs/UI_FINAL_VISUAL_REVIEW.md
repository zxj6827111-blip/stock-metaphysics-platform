## §1 首页（01）

**一致**：三栏外壳（左侧导航 / 中央内容 / 右侧系统状态）、Hero 标题层级、
"最近分析"三卡 + "系统状态"五行（引擎名 / 状态 / 延迟）、"平台能力"四卡横排。

**差异（保留）**
- 参考图最近分析卡内有三条**行情走势缩略图**；本平台没有把"最近分析"与行情绑定
  （最近分析是会话级记录，价格归行情源），因此不绘制 —— 不伪造价格曲线。
- 参考图搜索框内是"600519 / 贵州茅台"，本实现是纯代码 "600519"，
  提交后才解析为标的；这是输入交互差异，不是信息缺失。
- 参考图底部水印更明显；本实现页脚为版本号 + 一句题记。

**结论**：布局与信息层级一致；两处差异属数据契约差异，非缺陷。

## §2 综合研判（02）

**一致**：三模型评分卡（分数 / 方向 / 置信度 / 正负因素计数）、共识卡、冲突监测卡、
未来时间窗口图、历史验证摘要、关键证据、数据质量与风险 —— 区块与顺序一致；
共识与冲突**并列**，未做平均。

**差异（保留）**
- 参考图历史验证摘要有收益率分布直方图与胜率数字；本实现演示模式按正态近似绘制并
  标注"示意分布"，真实模式给空态 —— 不把近似分布当真实统计。
- 参考图"综合总分"式聚合在本实现中不存在（既有 E2E 显式断言"不显示综合总分"）。

**结论**：结构对齐；差异属数据真实性要求。

## §3 八字详情（03）

**一致**：五行分布（横条 + 百分比，按木火土金水语义着色）、四柱表
（天干/地支/藏干/十神/纳音）、命局摘要（日主/旺衰/格局/喜神/用神/忌神）、
时间结构（大运 / 流年 / 流月 / 流日 四段 + 节点连线）、正负因素双列、古籍证据区。
四柱干支着色与参考图一致（非单一文本色）。

**差异（保留）**
- 参考图供例的古籍是《渊海子平》《三命通会》《滴天髓》并带断句引文；
  本实现显示**本地真实语料**的条目（如《滴天髓》断论），不复制参考图里的引文。
- 参考图"大运"卡标注"Variant A（假设）"；本实现默认 `variant_mode=not_applicable`
  时显示"不适用（股票无性别）"，**不默认填男命**（AGENTS.md §5）。这是硬约束下的必要差异。
- 参考图首屏底部可见"古籍证验与历史统计"完整区；本实现需滚动一屏才能看到完整内容，
  首屏露出该区标题与条目（几何实测：古籍证据区顶部约 1058px，见旧复核记录）。

**结论**：结构对齐；两处差异为数据契约与项目硬约束。

## §4 紫微斗数详情（04）

**一致**：左侧命盘 + 右侧观察栏的双栏结构、十二宫环绕方位关系、
中央命盘身份（公历/农历/四柱/时辰/命身/五行局/生年四化）、运限区（大限/小限/流年/
流月/流日/流时）、三方四正。

**差异（保留）**
- 参考图盘面是**圆形环状**排布；本实现是 4×4 网格环（十二宫方位关系一致，
  即地支环顺序正确），这是既定设计取舍（网格在定高条件下更可控）。
- 参考图右侧有"格局稳定，长期价值"这类**解读标签**；本实现展示该宫的**实际星曜与四化**
  （可核对），不生成解读标签。
- 参考图每宫显示全部星曜；本实现每类星曜固定一行（保证十二宫整盘进首屏），
  截断处显示 `+N`，并提供每宫「明细」按钮展开完整星曜 —— 本轮为此新增
  （修前只有 `title` 悬停提示，触屏与键盘不可达）。

**结论**：结构对齐；差异为设计取舍 + 解读纪律。

## §5 历史验证（05）— 差异较大且合理

**一致**：术数规则强度（确定性）→ 统计有效性（历史数据）的分区顺序；
持有期对比图；负对照状态标签；实验明细表（Factor ID / 方向 / 样本数 / 上升率 /
平均收益 / 超额收益 / p 值 / 版本）。

**差异（保留，差异最大的一页）**
- 参考图首屏即展示 8 个统计指标磁贴（样本数 1248 / 上升率 58.3% / 平均收益 6.21% /
  中位数 / 超额收益 / 最大回撤 / IC / 稳定性 / 样本外表现）与收益率分布直方图、
  年度稳定性、牛熊震荡分组、随机对照、出生日期平移对照五张图。
- 本实现**没有**这五张图与部分指标：需要逐样本收益序列、可复现组合规则或
  IC/稳定性口径，本平台当前契约不提供 → 页面明确写"统计摘要：不可用"并说明原因，
  演示模式亦是空态（未运行的研究不得编造）。
- 本实现把**真实入库实验**（`backtest_experiment` / `backtest_result`）的持有期对比
  画出来，并对 `INVALID_CONTROL` 实验给出显式警告条与 Jaccard 重合度。

**结论**：这是"数据能力差异"而非视觉缺陷。本项目 Phase 3 的研究结论是
`SUPPORTED_OUT_OF_SAMPLE = 0`，用参考图的满屏统计磁贴渲染会**暗示研究已验证有效**，
属于任务书禁止的"为效果图改变研究结论"。**保留差异。**

## §8 黄历 / 日课（08）— 差异较大且合理

**一致**：今日黄历原始字段（农历 / 干支 / 生肖 / 纳音 / 建除十二值 / 十二神 / 黄黑道 /
冲煞 / 二十八宿 / 彭祖百忌 / 财神方位 / 喜神方位 / 胎神）、宜忌双列、未来交易日日期卡网格、
日课分类的历史表现区。

**差异（保留，差异最大的一页之一）**
- 参考图有"综合评分 68/100""风险等级 中""建议仓位 5-7 成""交易胜率 62%"等
  **衍生结论**，以及"未来关键吉日"表中逐日的胜率与主推原因；
  本实现**全部不产出** —— 没有经回测验证的仓位/胜率模型，写出来就是伪造研究结论。
- 参考图日期卡有"可交易/观望/忌交易"三态与"平"日；本实现按项目规则只产出**吉/凶**两级，
  第三类在响应中标注 `third_category_supported=false` 并说明差异原因（不补齐）。
- 本实现额外提供"逐卡日历来源"（实测成交日 / 官方已公布），参考图没有这一层。

**结论**：保留差异。本页是本项目**诚实性优先于观感**最集中的一页。

## §9 古籍证据检索（09）

**一致**：左检索结果 / 右聚合与详情的双栏结构；检索框；证据列表；选中证据详情
（原典原文 → 项目解释 → 关联主题与因子）；分类计数。

**差异（保留）**
- 参考图证据列表 128 条并按**相似度**排序、带相似度百分比徽标、类别与相似度筛选器；
  本实现是**本次分析触发的检索结果**（16 条，由驱动因子构造检索词，后端 BM25 + 主题匹配），
  在页面上明确写"不是全库语义检索，输入框只在这个结果集内筛选"。
- 本实现列表按**反证 → 支持 → 中性**排序（首条 `data-stance=counter`，E2E 硬断言），
  参考图按相似度排序 —— 这是研究纪律要求："反证不得被支持证据挤到末尾"。
- 参考图聚合区用条形图 + 圆环结构；本实现用三块计数（反证 6 / 支持 6 / 中性 4）+ 比例说明，
  计数全部落在首屏（几何实测底边 483）。

**结论**：结构对齐；排序与检索范围差异为纪律要求。

## §10 时间窗口（10）— 差异较大且合理

**一致**：摘要卡行 → 主视图 + 右侧解释栏的双栏结构；月度/周度/逐日三种粒度；
周度排名表；窗口解释联动。

**差异（保留，差异最大的一页之一）**
- 参考图主视图是**四条平滑插值曲线**（含"综合共识"线）配高共识区/观察区/高冲突区
  色带填充，跨 6 个月；本实现画的是**离散点折线**（三个模型各自的逐日规则强度），
  并在图注写明"只画三个模型各自的原始分数，不把日度分数插值成到每一天的曲线，
  因此这里不合成'第四条线'"。
- 参考图有"月历热力图"与"关键触发因子"卡片；本实现的审计入口是逐日/逐月表格 +
  来源与方法，热力图以离散观点带替代（任务书 §R3 明确要求"用离散观点带，
  不把规则分数插值成未来价格预测"）。
- 参考图的窗口解释在未选中时是"最佳布局窗口"等**结论式**文案；
  本实现未选中时显示"窗口解释：暂无数据"，选中后给出该日/该周/该月的真实结果与风险。

**结论**：保留差异。插值曲线与结论式文案都会把"规则强度"读成"未来走势预测"。

## 总结：三类差异的归属

1. **数据契约差异**（本平台接口未提供该字段 → 空态 + 说明）：
   收益率分布、策略净值、逐年稳定性、IC/稳定性、逐因子历史胜率、多维度雷达、
   历史类似分歧的后续涨跌、日课交易胜率与仓位建议。
2. **研究纪律差异**（有数据但**不得**那样呈现）：
   不用平均分掩盖冲突、不插值成预测曲线、不补第三级吉凶、反证必须排前面、
   不给"综合总分"、不默认填男命。
3. **设计取舍差异**（数据相同、呈现方式不同）：
   紫微用网格环而非圆环、证据检索范围限定在本次结果集、
   时间窗口用离散点带而非插值曲线。

**没有任何一处差异是为了"更好看"而修改计算结果。**
