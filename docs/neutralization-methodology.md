# Phase 3E · 市场 / 行业 / 风格中性化方法学

> 生成基线：commit `b04a2b9` · `split_version=phase3-oos-v1` · `calibration_version=cal-v1`（`fit_hash=7e9897570d3b5a28`）
> 数据集：universe `v2-phase3a` 500 只（333 退市 + 167 在市）× 3 出生模型 × 18 预注册对象 × 4 持有期 × 3 分区 = **648 行结果**
> 数据源：`data/phase3_universe/phase3e_neutralization_results.csv`、`phase3e_neutralization_meta.json`、`phase3e_exposure_coverage.csv`

**先读这一句**：中性化不是"把结果做好看"的手段 —— 它的作用是判断**已观察到的差异**是否只是市场、板块或风格的暴露。本阶段由此得到的最重要结论是：**部分对象在风格中性化后符号翻转**，说明它们的表面效应主要来自风格暴露；同时**没有任何对象在中性化后变得更强**。

## 1. 市场中性化（GOAL §3E-1）

### 1.1 基准选择

| 项目 | 值 |
|---|---|
| 基准 | `IDX000300`（沪深 300） |
| 映射规则 | **统一基准**：全部股票共用同一条指数收益 |
| 分层映射 | `BENCHMARK_SPLIT_UNAVAILABLE` |
| 原因 | canonical 快照内只有 `IDX000300`，**不存在中证 500 / 中证 1000**，无法实现 GOAL 期望的"大盘→沪深300 / 中小盘→中证500" |
| 已知偏差方向 | 小盘股与沪深 300 走势背离时，规模暴露会混入超额收益 → 由 §3 的 size 维度单独量化 |

**没有用自建等权组合冒充中证 500**：那会引入一个与预注册口径不同的基准，事后无法解释差异来源。

### 1.2 口径

`market_excess_return_Nd = ret_Nd − bench_ret_Nd`，两端点使用**同一日历区间**（个股端点交易日之间），
由 `src/research/labels/horizon_returns.py` 统一产出。本阶段只是把它重命名为中性化口径并加校验：

* `raw_return_{h}d` —— 个股复权收益（`close × adj_factor`）
* `benchmark_return_{h}d` —— 同区间基准收益
* `market_excess_return_{h}d` —— 前者减后者，**这就是市场中性化后的效应量**

三段必须同时报告：只报第三列无法区分"个股涨"与"市场涨"。

## 2. 行业中性化（GOAL §3E-2）

**状态：`POINT_IN_TIME_INDUSTRY_UNAVAILABLE` 且 `INDUSTRY_CLASSIFICATION_UNAVAILABLE`（双重不可用）。**

排查范围与结论：

| 来源 | 是否含行业 | 结论 |
|---|---|---|
| `E:\AStockData` canonical blob（`composite_none`） | 否，只有 OHLCV | 不可用 |
| TuShare PIT universe 注册簿（`pit_universe_1d_20260717_*`） | 否，只有 `board` / `list_status` | 不可用 |
| 本地 TuShare 目录（`factors/` / `raw/`） | 否，只有 `adj_factor` 与退市日线 | 不可用 |
| `data/import/stocks.csv` | 有 `industry`，但只覆盖 Phase 1 的 20 只腾讯快照 | 与 500 只 universe 不重叠到可用程度 |

因此：

* **不做**行业中性化；
* 不使用当前行业冒充历史 PIT 行业（那等于把未来信息写进历史横截面）；
* 不联网抓取后冒充权威分类；
* 由此**不得**声称做过"严格 industry-neutral backtest"。

### 2.1 替代控制：板块（segment）

`board` 来自 Phase 3A 的 PIT 注册簿，是**法定板块归属**（`sse_main` 196 / `szse_main` 111 / `szse_sme_legacy` 85 / `chinext` 86 / `star` 22），
不是行业。本阶段把它作为 `SEGMENT_CONTROL_BOARD` 提供，用于回答"是不是某个板块整体在动"：

`segment_neutral_value = 该股收益 − 同 (as_of, 板块) 等权均值`（组内成员 < 3 只时不出值）。

**它不能替代行业中性化**，报告与结论均按"板块控制"解释。行业中性化维度在 3F 的
稳健性检查中记为 `ROBUSTNESS_DIMENSION_UNAVAILABLE`。

## 3. 风格控制（GOAL §3E-3）

### 3.1 可得性（2026-09-20 实测）

| 维度 | 状态 | 口径 |
|---|---|---|
| size（**真实市值**） | `MARKET_CAP_UNAVAILABLE` | canonical 快照没有总股本/流通股本，也没有 `daily_basic` 类基本面表 |
| size（**代理**） | `SIZE_PROXY_LIQUIDITY_AMOUNT` | trailing 20 个交易日**均成交额的对数** —— 这是流动性代理，**不是市值** |
| momentum | 可用 | trailing 60 / 120 个交易日累计收益（复权价） |
| volatility | 可用 | trailing 20 / 60 个交易日**日对数收益**标准差 |
| value（PE/PB 等） | `VALUE_FACTOR_UNAVAILABLE` | 无 PIT 基本面，**不伪造** |

暴露覆盖率（`phase3e_exposure_coverage.csv`）：

| 暴露列 | 覆盖率 |
|---|---:|
| `momentum_60d` | 0.9922 |
| `momentum_120d` | 0.9843 |
| `volatility_20d` | 0.9971 |
| `volatility_60d` | 0.9922 |
| `size_proxy_log_amount_20d` | 0.9973 |

未覆盖 = 历史长度不足（上市晚）或数据不足 → **NaN，不填 0**。

### 3.2 防未来数据泄漏

所有暴露都在 `trade_date <= as_of` 的 bar 上计算。这不是靠人工检查，而是
`tests/research/test_style_exposures.py` 里的硬断言：**把 as_of 之后的 bar 篡改成 1000 倍，
暴露值必须逐位不变**（`test_exposures_are_frozen_against_future_bars`）。

### 3.3 风格中性化的两种口径

1. **残差均值**（`style_neutral_hit_mean`）：在每个 `as_of` 横截面上做
   `excess_return ~ 1 + 5 个 z-score 化暴露` 的 OLS，取残差，再对命中子集求日期等权均值。
2. **控制后系数**（`controlled_hit_coefficient`）：`excess_return ~ 1 + 暴露 + 命中虚拟变量`，
   取命中系数的逐日平均与 t 值。它直接回答"在暴露相同的条件下，命中组比未命中组好多少"。

`style_r2_mean` 给出风格暴露能解释的横截面方差比例：OOS 20D 为 **0.1992**（约 20%）。

## 4. 横截面统计（GOAL §3E-4）

全部统计**先按 `as_of` 计算、再跨日平均**（date-clustered），自由度 = 有效日数 − 1：

| 统计量 | 口径 |
|---|---|
| `event_rank_ic_*` | 逐日 Spearman(命中指示, 未来超额)，跨日平均 + t |
| `factor_rank_ic_*` | 单引擎对象用引擎自身的连续分数（raw 用 `opinion_score`，calibrated 用 `research_percentile`）；多引擎对象记 `NOT_APPLICABLE_MULTI_ENGINE`（**不自造合成分数**） |
| hit / non-hit 分组收益 | 各自日期等权均值（pooled 值同时保留） |
| `long_short_spread` | 逐日 (命中均值 − 未命中均值)，跨日平均 + t |
| `controlled_hit_coefficient` | 见 §3.3 |
| 日期效应 | 见 [`huangli-date-effect-analysis.md`](huangli-date-effect-analysis.md) |

> **`long_short_spread` 只是研究统计量**：未计交易成本、流动性、涨跌停与卖空约束，
> 不构成任何交易策略建议。

### 4.1 为什么不报告行级 p 值作为主口径

同一个 `as_of` 上 200+ 只股票共享同一段市场行情，**不是独立样本**。
Phase 3D 已经用黄历实证过：行级与日级口径可以给出方向相反的结论。
本阶段所有显著性均以日期为观测单位。

## 5. 结果（OOS，主持有期 20D，`listing_open_v1`，如实全列）

`hit_date_mean` = 命中子集的日期等权市场超额；`style_neutral` = 风格正交化后的残差均值；
`ctrl_coef` = 控制风格后命中虚拟变量系数（t 值在括号内）；`seg_neutral` = 板块去均值后命中均值。

| 对象 | 命中数 | hit_date_mean | style_neutral | ctrl_coef (t) | seg_neutral |
|---|---:|---:|---:|---:|---:|
| 八字 raw | 3132 | −1.91% | −0.04% | −0.40% (−0.60) | −0.005% |
| 八字 calibrated | 831 | −1.21% | +0.82% | +1.09% (1.36) | +0.70% |
| 紫微 raw | 755 | −1.60% | +0.19% | +0.24% (0.46) | +0.25% |
| 紫微 calibrated | 678 | −1.61% | +0.20% | +0.25% (0.45) | +0.23% |
| 黄历 raw | 1459 | −1.78% | +0.19% | +0.62% (0.92) | +0.02% |
| 黄历 calibrated | 837 | **+1.01%** | **+2.00%** | **+4.11% (1.97)** | +0.81% |
| 八字+紫微 raw | 731 | −1.68% | +0.03% | +0.03% (0.06) | +0.17% |
| 八字+紫微 cal | 175 | −1.61% | +0.05% | +0.78% (0.59) | −0.19% |
| 八字+黄历 raw | 1407 | −1.79% | +0.14% | +0.30% (0.52) | +0.02% |
| 八字+黄历 cal | 279 | +0.48% | +1.38% | +4.64% (2.15) | +0.59% |
| 紫微+黄历 raw | 328 | −1.22% | +1.58% | +1.79% (1.55) | +0.49% |
| 紫微+黄历 cal | 172 | +3.03% | **−1.96%** | +5.12% (1.36) | −1.40% |
| 三模型 raw | 320 | −1.16% | +1.68% | +1.88% (1.62) | +0.58% |
| 三模型 cal | 64 | +0.90% | **−4.99%** | +3.28% (0.93) | −3.35% |

**读数要点（不做美化）**：

1. **符号翻转是双向的**：`紫微+黄历 cal`、`三模型 cal`、`八字 raw` 在风格中性化后由正转负；
   `黄历 cal`、`八字+黄历 cal` 反而由小转大。这说明"风格中性化"不是单向的"杀死信号"开关，
   两种口径测的是不同的东西（残差均值 vs 控制后系数），**必须同时报告**。
2. **只有 2 个对象的控制后系数 |t| ≥ 2**（黄历 cal 1.97、八字+黄历 cal 2.15）。
   在 42–54 个实验里出现 2 个名义 t ≈ 2 属于多重检验下完全可预期的噪声水平 ——
   这正是 Phase 3F 必须做 BH-FDR 的原因，也解释了 3F 的最终结果（正式 gate 实验 **FDR 通过 0 个**）。
3. **风格暴露解释约 20% 的横截面方差**（`style_r2_mean = 0.1992`），
   因此它对效应量的影响量级与观察到的效应量同阶，**不能忽略风格控制**。
4. **没有出现"中性化后更强"的情形**：本阶段没有任何对象因中性化而获得更可信的信号。

## 6. 回答 GOAL §3E-5 的 Q-E1..Q-E5

| 问题 | 回答 |
|---|---|
| **Q-E1** 八字 calibrated 的 OOS 结果做 market neutral 后是否改变？ | **会**。命中子集的原始收益均值与市场超额之差即基准收益（约 +0.03% 至 +0.11%），扣除后三个出生模型的命中超额分别为 −1.57% / −1.74% / −1.23%（与 3D 报告一致）；风格中性化后变为 +0.82% / +0.17% / +0.65%，控制后系数 +1.09% / +0.37% / +0.93%（t 分别 1.36 / 0.57 / 1.87）。**结论：数值改变、符号改变，但没有任何一项达到 3F 的校正门槛。** |
| **Q-E2** 紫微是否存在市场暴露解释？ | **部分是**。紫微命中子集的原始收益为 −1.60% ~ −2.24%，扣除基准（约 −0.3% ~ +0.3%）后剩余 −1.39% ~ −2.39% 仍为负；**市场暴露不能解释紫微的负超额**。风格中性化后其残差均值转为小幅正（+0.19% ~ +0.20%），说明**负效应里有一部分来自风格暴露**。 |
| **Q-E3** 黄历的日期效应是否其实是市场-wide calendar effect？ | **不是**。见 [`huangli-date-effect-analysis.md`](huangli-date-effect-analysis.md)：命中比例斜率在 TRAIN 为 +0.044（t=1.15）、OOS 为 −0.066 ~ −0.108（|t| ≤ 1.94），**符号相反且均不显著**，未形成稳定的日历结构。 |
| **Q-E4** Consensus 在控制市场后是否仍然 NO_SIGNAL？ | **是**。共振对象（八字+紫微 / 三模型）的控制后系数 t 值分别为 0.59 / 0.93（cal）与 0.06 / 1.62（raw），全部低于 2；且 3F 中它们全部未通过 FDR。 |
| **Q-E5** 任何看似较好的结果，是否被 size / momentum / volatility 解释？ | **部分被解释，部分相反**。`紫微+黄历 cal`（+3.03% → −1.96%）与 `三模型 cal`（+0.90% → −4.99%）在风格中性化后**符号翻转**，属"看起来好但主要来自风格"；`黄历 cal` 与 `八字+黄历 cal` 反而上升，但其名义 t ≈ 2 在多重检验下不可解锁。**没有任何结果在 3F 校正后仍成立。** |

## 7. 限制

1. **行业维度完全缺失**（`POINT_IN_TIME_INDUSTRY_UNAVAILABLE`）：无法回答"是不是产业周期"。
2. **size 是流动性代理而非市值**：它是 proxy，与市值相关但不等价。
3. **value 维度完全缺失**：没有 PIT 基本面，不做任何替代。
4. **统一基准**：大中小盘共用沪深 300，规模暴露会混入超额收益（已由 size 维度量化）。
5. **未计交易成本 / 流动性 / 涨跌停 / 卖空约束**：这是信息量检验，不是可交易性检验。
6. **残差均值的噪声较大**：`style_neutral_hit_mean` 逐日估计后跨日平均，在日数只有 15 的 OOS 上
   标准误偏大，因此**控制后系数**是更稳健的口径（两者都已报告）。
