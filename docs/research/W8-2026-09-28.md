## 紫微故障与恢复演练

`HttpZiweiTransport.available()` 保持为不发网络请求的配置检查；状态端点新增 1 秒超时的 `/health` 探测，验证 HTTP 200 与 JSON `status=ok`。因此盘面计算路径不增加网络探测，`/api/v1/system/engines` 与 `/api/v2/system/readiness` 则反映常驻服务真实状态。

| 阶段 | 观测结果 |
|---|---|
