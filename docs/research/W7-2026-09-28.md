# W7 页面与报告闭环验收（2026-09-28）

## 范围与结论

W7 将现有研究终端连接到 W4/W5/W6 已有 v2 查询能力：首页分别展示行情快照截止日和历史数据集范围；日期扫描结果可进入 v2 历史事件研究；时间轴通过服务端 Fortune v2 展示出生档案及显式假设；实验页读取三项冻结实验报告；历史研究页分别请求 1、5、20 日结果，并可导出页面同一批数据集、请求口径和 API 响应。

**前端工程验收通过；真实后端及认证数据验收留给 W8。**本工作包没有修改 API 契约，保留 v1 页面与历史实验档案；没有开展视觉重设计。页面保留 loading、empty、error 和 unavailable 状态，并将未认证、未生成、样本不足、不可用和无匹配事件分开表达。

## 实现范围

| 区域 | 实现 |
|---|---|
| 首页 | 独立显示行情来源/版本/截止日与历史数据集时间范围、分片覆盖、研究及确认性资格和登记限制 |
| 日期扫描 | 为三种已支持关系提供明确因子映射，生成带日期、关系及因子的历史验证入口；其他关系要求选择因子，不自动推断 |
| 历史验证 v2 | 固定数据集和版本选择；支持股票/日期范围、因子与激活条件；分开保留 1/5/20 日响应、错误和事件明细 |
| 股票时间轴 | 请求 Fortune v2，显示服务端出生基准、时间精度、假设、来源、点位可用性和版本溯源；保留原 v1 时间轴 |
| 实验室 | 展示 F5-EXP-001/002/003 的冻结 v2 报告、资格、数据集、协议、检验族校正、逐项状态及负对照；旧 v1 存档继续可读 |
| 报告导出 | Markdown/JSON 从页面当前使用的 v2 数据集、请求和 API 响应导出，保留 null、缺失原因、指标、数据限制和状态 |

页面默认工程数据集 `w4-engineering-002561-20120223-asof-v2` 只有 20 个日期、1 只证券，且 `research_eligible=false`、`confirmatory_research_eligible=false`。它用于工程连通与回放，不能作为认证范围或确认性研究结果。W2 当前仍为 `COVERAGE_INCOMPLETE`；W6 冻结实验保持探索性/样本不足结论，W7 不改变该结论。
