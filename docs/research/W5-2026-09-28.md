## API 与边界

- `POST /api/v2/research/fortune/timeline`：请求只传代码、日期和条件；服务端经当前行情 provider 解析身份及最早日线观测，保留来源和版本。
- `POST /api/v2/research/fortune/scan`：服务端按已登记 PIT 证据和 `list_date <= T < delist_date` 形成股票池，再执行 F4 scanner；每次最多 5,000 个成员，超过时在读取证券资料前拒绝整次扫描，不缩小 universe。
- `POST /api/v2/research/event-study`：显式选择 W4 dataset、范围、因子、激活条件、目标周期和完整版本组；只读取 manifest 登记且 SHA-256 核验通过的分片。单次候选观察上限 250,000，先计数，超限时拒绝查询，不截断数据后伪装完整统计。
- `GET /api/v2/research/datasets/{dataset_id}`：提供固定数据根下的 manifest、分片、版本和资格。
- `GET /api/v2/research/experiments/{experiment_id}`：提供 W6 固定根下的版本化实验 JSON 报告。
- W1 的 `/api/v2/system/readiness` 保持原实现；v1 health 与 Fortune 路由保持不变。

事件接口仅产出描述统计和分页事件。degraded 行不进入收益统计；未认证数据仍显示为 `EXPLORATORY_NOT_GATED`，缺少命中时为 `INSUFFICIENT_SAMPLE`。这不是显著性检验，也不表达收益或交易建议。
