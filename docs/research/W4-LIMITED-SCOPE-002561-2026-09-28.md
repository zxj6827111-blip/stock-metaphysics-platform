1. 校验七个 feature/outcome Parquet 分片的 SHA-256；
2. 从 W4 每行引用重建 SQLite `chart_artifact` canonical payload，逐项比对全部 4,539 个 SHA-256；
3. 从 pinned raw、factor 和 `adjustment=none` benchmark 文件独立复算 2012-02-23、2015-04-29、2018-05-14 三个日期的 1/5/20 日个股、基准与超额收益及结束日期；
4. 要求结果与 W4 六位小数标签完全一致。

执行命令：

```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONDONTWRITEBYTECODE = "1"
.\.venv\Scripts\python.exe scripts\audit_w4_limited_scope.py
```
