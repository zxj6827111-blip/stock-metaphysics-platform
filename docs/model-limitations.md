# 已知限制（Model Limitations）

> 本文件是**必须随报告一起阅读**的限制清单。
> 任何引用本系统输出的结论，都必须同时引用本文件。

---

## 一、最重要的三条

### 1. 术数对股票收益没有已确认的因果关系

传统八字、紫微、黄历与股票未来收益之间**不存在经现代金融科学确认的稳定因果关系**。

本项目的价值不在于"证明术数很准"，而在于**用可复现的方法回答
"哪些传统结构在历史数据上确实有统计关系，哪些没有"**。

截至 Phase 2 的实际研究结果：**没有发现稳定的预测能力**
（`NO_SIGNAL` / `INCONCLUSIVE` / `INVALID_CONTROL`，详见 `docs/PHASE2_ACCEPTANCE_REPORT.md`）。

### 2. 分数不是概率，也不是收益率

* `opinion.score`（0–100）是**该术数内部规则强度指标**；
* `factor.rule_score`（0–10）是**传统规则强度分**；
* 两者都**不代表预期收益率，也不代表上涨概率**。

历史统计另存在 `research_status` / `historical_stats`，两者必须分开阅读。

### 3. 共识不等于有效

`STRONG_POSITIVE_CONSENSUS` 只表示"模型之间方向一致"。
它**不表示**"历史上这样判断是有效的"。
系统完全可能输出 `高共识 + NO_SIGNAL`，且这在实际样本上是常见结果。

## 二、出生模型（最大的单一假设）

| # | 限制 | 影响 |
|---|---|---|
| 1 | **股票没有真实出生时间**。默认基准 `listing_open` = 上市首个正式交易日 + 交易所正式开盘 + Asia/Shanghai，这是一个**研究假设**而非事实 | 换一个基准会得到完全不同的盘面 |
| 2 | 出生模型本身**尚未被回测检验**（四种候选基准 `ipo_date` / `company_foundation` / `first_trade` / `custom` 未做对比研究） | 不能宣称"上市首日就是它的出生时间" |
| 3 | 开盘时刻取自 `config/exchange_session_calendar.json`（A 股统一 09:30） | 特殊时段（如科创板盘后固定价格交易）未纳入 |

### 2.1 出生模型的直接后果：部分因子结构性地恒定

**实例（已量化）**：`Z_LIFE_006`（身宫与命宫同宫）在 20 只股票 × 5 个时点 × 2 variant
= **9,800 行观测上恒为 False**。

原因不是实现 bug，而是出生模型的结构性后果：紫微中"命身同宫"只发生在**子时出生**者身上，
而 `listing_open` 基准取的开盘时刻恒为 **09:30（巳时）**。
因此该因子在默认出生模型下**不携带任何信息**。

它不被删除（对未来可能引入的非交易时段基准仍有意义），但已被标记
`CONSTANT_FACTOR` / `LOW_DISCRIMINATION_FACTOR`（见 `docs/factor_quality_report.md` 附录 A）。

## 三、股票没有真实性别（运限方向假设）

* `variant_mode` 默认 `not_applicable`，该模式下八字**不输出大运**；
* 紫微需要显式方向：`forward`（顺行）/ `reverse`（逆行）/ `both`；
* 系统**不会**默认男命或女命（ADR-0003 / ADR-0010）。

**最关键的一条限制**：

> 紫微的顺行/逆行 variant 差异**仅限于大限/小限顺逆与长生十二神顺逆**。
> 十二宫、全部星曜、生年四化、三方四正、流年/流月/流日/流时与 variant 无关。
>
> 因此 **Variant A 与 Variant B 不是两条独立证据**，
> 「两者结论一致」**不能**当作双重确认。

量化差异清单见 `docs/calculation-differences-phase2-ziwei.md` D4。

---

## 四、紫微股票映射是研究假设，不是传统定论

「财帛宫 = 资金/价格」「官禄宫 = 公司经营」「迁移宫 = 外部市场」等映射
**不是传统紫微斗数的规定**，而是本项目的研究假设
（版本号 `ziwei_stock_mapping_version = ziwei_stock_mapping_v1`）。

* 禁止在 UI / 文档 / 报告中表述为"传统紫微规定财帛宫就是股价"；
* 映射本身必须先经历史回测检验；
* 所有这类因子在字典中带 `research_mapping` 标签，定义文本中显式声明"研究映射"。

## 五、紫微引擎的限制

| # | 限制 | 影响 |
|---|---|---|
| 1 | **没有第二实现源交叉验证**（Tianji 未接入，许可证未核实） | 紫微结论只有结构性不变量与快照锁定，没有独立复核 |
| 2 | 小限层**不提供流曜**（iztro 事实） | `Z_AGE_*` 因子只能用宫位/干支/四化，不能用流曜 |
| 3 | 晚子时（23:00–24:00）计为 `timeIndex=12` | 23 点后出生者的命宫可能与其他流派相差一日 |
| 4 | 闰月口径固定 `fixLeap=true` | 闰月出生者的月支归属可能与其他流派不同 |
| 5 | 首次引入 Node.js 运行时依赖 | 容器部署必须起 `ziwei` 服务；子进程 transport 在高并发下是瓶颈 |
| 6 | iztro 升级会改变口径 | 必须重跑 Golden 并把差异写入 `docs/calculation-differences-phase2-ziwei.md` |

## 六、统计方法的限制

> 本节在 Phase 3D 后已按实况更新：编号 1/2/5 描述的旧限制已被 Phase 3A–3D 消除或改写，
> 现状见各条"现状"栏。仍未被解除的限制（3、4、6、7）继续有效。

| # | 限制 | 影响 | 现状（2026-09-20） |
|---|---|---|---|
| 1 | **样本规模** | 样本小则不足以做强统计结论 | **已扩容**：`v2-phase3a` 500 只（333 退市 + 167 在市），1.74M 行日线，1990-12-19 起 |
| 2 | **生存者偏差** | 只用当前上市股票会使结论偏乐观 | **已缓解**：PIT universe 含 333 只退市股（ADR-0012）；退市股在其退市日之后不再产生事件 |
| 3 | **无交易成本假设** | 收益计算忽略成本、滑点、税费 | 未变：结论偏乐观 |
| 4 | **无多重检验校正** | 只产出 Bonferroni 参考阈值与警告 | 未变：Phase 3F 负责 BH-FDR；Phase 3D 因此**不产出** `SUPPORTED_OUT_OF_SAMPLE` |
| 5 | **样本外验证** | 此前无样本外管线，不得外推任何有效性 | **已建立**：Phase 3D 固定 holdout（TRAIN 2010–2018 / VALIDATION 2019–2022 / OOS 2023–2026-08）+ 扩窗 walk-forward（逐 fold 重拟合）。**结论仍未解锁**：最高状态是 `OOS_CANDIDATE_SUPPORTED`，且必须等 3F 的 FDR 校正 |
| 6 | **未做行业中性化 / 风格中性化** | 无法区分"术数信息"与"行业暴露" | 未变：Phase 3E 负责；当前行业切片标记 `POINT_IN_TIME_INDUSTRY_UNAVAILABLE` |
| 7 | **复权口径** | 未对比其他口径 | **已明确**：canonical 为 `composite_none`（不复权原始价），收益一律用 `close × adj_factor` 推导（HFQ 锚定），口径记录在 `label_version=phase3d-hfq-adjfactor-v1` |
| 8 | **事件集区分度是硬约束** | Jaccard > 0.9 直接判 `INVALID_CONTROL` | 未变，且 Phase 3D 已确认其结构性后果：原始 `BAZI_POS` 正向率 94%–96.6% → 事件集合接近整个可用池 → 随机类负对照在该口径下必然失效 |

## 九、明确不做的事

本系统**不提供**：

* 自动交易、券商接口、下单；
* 资金账户、持仓管理；
* 付费会员、复杂多租户；
* 六爻、奇门遁甲引擎（仅预留接口）；
* 任何形式的投资建议、目标价、仓位建议。

---

## 十、引用本系统输出时的强制要求

任何引用都必须同时说明：

1. **ResearchStatus**（`NO_SIGNAL` / `NO_REAL_DATA` / `INVALID_CONTROL` … 必须原样引用）；
2. **样本范围**（几只股票、哪个时间区间、`market_data_version`）；
3. **分数语义**（"规则强度"而不是"上涨概率"）；
4. **本文件**（`docs/model-limitations.md`）。

缺少任何一项的引用都**不成立**。
