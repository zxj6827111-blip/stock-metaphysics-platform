# ADR-0007：涨跌配色采用 A 股惯例（红涨绿跌）

- **状态**：已接受（Phase 1）；**与 UI 规范文档存在有意偏差**
- **日期**：2026-09-18
- **影响**：设计令牌、全部页面、UI 复刻 notes

## 背景

UI 规范文档 `uiux_spec_v1.md` §2 规定：

> 状态色只表示语义：
> ```
> Positive      偏青绿
> Negative      偏朱红
> ```

但参考图 `doc/ui-reference/*.png`（用户指定的"Visual Source of Truth"）实际使用的是：

| 参考图中的元素 | 颜色 |
|---|---|
| `600519 贵州茅台 1682.30 +1.24%` | **红色** |
| `000001 平安银行 10.24 -0.39%` | **绿色** |
| `上涨率 68.9%` / `平均收益 +12.6%` / `超额收益 +8.4%` | **红色** |
| `最大回撤 -18.7%` | **绿色** |

即 **红涨绿跌**（A 股/东亚市场惯例），与规范文档相反。

用户指令第 21 条要求"需要尽可能 1:1 还原：……颜色"，第 22 条要求
"视觉结构：以效果图为准"；而指令给出的资料优先级顺序中 PNG Reference 排在
UIUX Spec 之后。两条要求在这一点上冲突。

## 决策

**采用参考图的红涨绿跌配色。**

理由（按权重排序）：

1. **领域正确性**：A 股用户对"红涨绿跌"有极强的既有预期。
   用绿色表示上涨在中国资本市场语境下会造成**严重误读**，
   这是一个可能影响用户决策的错误，不是审美偏好问题。
2. **参考图一致性**：参考图是用户明确指定的视觉真值，
   且复刻验收的核心标准是"用户一眼看过去是同一个系统"。
3. **规范文档的意图被保留**：规范文档的核心要求是
   "状态色只表示语义"（即不要用颜色表达吉凶），这一点被完整保留 ——
   红色只表示"数值为正 / 方向向上"，不表示"吉利"。

## 实现

```css
--color-up:   #E8585A;   /* 上涨 / 正向 —— 取自参考图 600519 的涨跌幅颜色 */
--color-down: #4FD39B;   /* 下跌 / 负向 —— 取自参考图 000001 的涨跌幅颜色 */
--color-flat: #7C8FA3;   /* 中性 */
```

### 关键补偿措施：不依赖颜色单独传达信息

由于"红涨绿跌"对非中文用户是反直觉的，系统**所有方向指示都同时使用三重编码**：

| 编码 | 实现 |
|---|---|
| 颜色 | `var(--color-up)` / `var(--color-down)` / `var(--color-flat)` |
| 箭头符号 | `↑` / `↓` / `→`（`DirectionMark` 组件） |
| 数值符号 | `+` / `−` / `0` |

```tsx
<span className="w-[68px]">八字</span>
<DirectionMark direction={d.direction} />   {/* ↑ ↓ → */}
<span className="smp-num">{d.direction > 0 ? "+" : d.direction < 0 ? "−" : "0"}</span>
```

这同时满足 `uiux_spec_v1.md` §31 的可访问性要求
（"正负方向不能只靠颜色，必须同时有 ↑ ↓ → ⚠"）。

## 后果

**正面**

* 符合 A 股用户预期，避免方向误读；
* 与参考图 1:1；
* 三重编码提供了面向色觉障碍与非中文用户的兼容性。

**负面**

* 与规范文档存在**显式偏差**，需要文档化
  （本 ADR + `docs/ui-implementation.md` §3.3 + 各页 `notes.md`）；
* 如果未来做国际化（美股/港股），需要按市场切换配色约定。

## Phase 2 如果要改回规范文档配色

必须同步修改：

1. `apps/web/app/globals.css` 的 `--color-up` / `--color-down`；
2. 复查所有页面中**硬编码**的红/绿色（应已全部走 token）；
3. 更新 `apps/web/artifacts/ui-review/*/notes.md` 的"仍有差异"部分；
4. 更新 `docs/ui-implementation.md` §3.3；
5. **重新截图并人工确认**（配色改动影响面大）。
